## Overview

Aitor Rienda lets you organize documentation by project, making it simple to manage all your docs in one place.

## Steps

1. Go to `Projects` on the left menu
2. Click `New Project`
3. Enter a name and description
4. Add documents or folders as needed
5. Drag to reorder or group similar docs

## Tips

- Use folders for large projects
- Add tags to help search
- Collaborate by inviting teammates
